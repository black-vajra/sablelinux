# SableLinux Recovery to ISO Plan

## Objective

Rebuild SableLinux into a reproducible live/install ISO project.

Immediate deliverable:

- Live ISO boots on Z890, HP EliteBook, HP Pavilion, and ASUS laptop.
- Live environment provides Sway, waybar, wired networking, WiFi support, terminal, Firefox, and installer.
- Installer succeeds in a QEMU/OVMF VM simulating an EliteBook-level target.
- Installed VM boots independently to Sway with networking functional.
- GitHub repository reflects the new release-engineering stance.

## Sources of Truth

1. Z890 installed SableLinux system — development head.
2. HP EliteBook installed SableLinux system — proven deployment baseline.
3. BUILDLOG.md — chronological engineering record.
4. Git repository — scripts and documentation.
5. Backup drives — recovery material.
6. Claude-derived documents — historical/inferred context only.

## Current State

Old live staging directories are absent and considered invalid:

- /mnt/liveroot*
- /mnt/live*
- /tmp/usb-root

Therefore the live/install pipeline will be reconstructed cleanly.

## Workflow

### Phase 1 — Establish Project Structure

Create canonical engineering directories:

- docs/architecture
- docs/engineering
- docs/release
- docs/recovery
- docs/testing
- docs/reference
- build-live
- manifests
- scripts/live
- scripts/install
- scripts/test
- scripts/recovery

### Phase 2 — Inventory Reference Systems

Capture Z890 installed system inventory.

Capture HP EliteBook installed system inventory.

Store outputs under:

- docs/reference/inventory/z890/
- docs/reference/inventory/elitebook/

### Phase 3 — Rebuild Live Root

Create a clean staging root from the Z890 installation.

Transform it into a live environment:

- create sable live user
- remove host identity
- strip fstab
- clear logs and histories
- configure autologin
- configure Sway/waybar
- configure PipeWire user services
- include WiFi helper
- remove hardcoded GPU paths
- preserve installer

### Phase 4 — Rebuild Live Boot Components

Create scripts for:

- live root preparation
- squashfs generation
- busybox initramfs generation
- standalone GRUB EFI generation
- raw VM disk image generation

The initramfs must use:

- findfs LABEL=SABLELINUX
- squashfs lowerdir
- tmpfs overlay upperdir
- switch_root to systemd

### Phase 5 — VM-First Validation

No physical USB testing until VM testing passes.

Validate in QEMU/OVMF:

- GRUB loads
- kernel boots
- initramfs finds live partition
- squashfs mounts
- overlay mounts
- switch_root succeeds
- systemd boots
- sable autologin works
- Sway starts
- waybar starts
- networking works
- Firefox launches

### Phase 6 — Simulated EliteBook Install

Attach a second VM disk.

Run sable-install non-LUKS first.

Boot installed target independently.

Validate:

- GRUB
- kernel
- systemd
- user login
- Sway
- waybar
- networking
- PipeWire

LUKS testing remains deferred until initramfs cryptsetup support is explicitly implemented.

### Phase 7 — Physical Live Validation

Only after VM success, write ISO to USB.

Validate live boot only on:

- Z890
- HP EliteBook
- HP Pavilion
- ASUS laptop

Do not overwrite working physical installations.

### Phase 8 — Release Baseline

When validation passes:

- tag release candidate
- archive ISO, raw image, squashfs, initramfs, kernel, logs, commit hash
- update BUILDLOG.md
- update engineering state docs

## Rule

The live USB is no longer hand-crafted. It must be generated by scripts from documented inputs.
