## Architecture Decisions

### Installer account provisioning

- Root account UID 0 always exists.
- Installer requires user-selected username and password.
- Default administrative model: password-based sudo via wheel.
- Default root password authentication: locked.
- Optional separate root password.
- Support sudo-only, root-only and combined administrator modes.
- SSH root login disabled by default independently of root password.
- Installed accounts must be provisioned independently from live accounts.
- No inherited live-session passwords or authentication overrides.
- Test all administrative modes on disposable qcow2 installations.

### Audio configuration

- Do not embed Z890-specific device identifiers in release artifacts.
- Validate appropriate output selection and persistence on test hardware.
- Investigate first-boot configuration only if regression testing
  demonstrates it is necessary.
